ОСТАЛСЯ ОДИН РАЗОВЫЙ ШАГ ДЛЯ АНКЕТЫ:
1. Откройте созданную Google Таблицу.
2. Расширения → Apps Script.
3. Удалите код по умолчанию и вставьте содержимое файла google-apps-script.gs.
4. Нажмите Deploy / Развернуть → New deployment / Новое развертывание → Web app / Веб-приложение.
5. Execute as / Выполнять от имени: Me / Я.
6. Who has access / У кого есть доступ: Anyone / Все.
7. Разверните и скопируйте URL веб-приложения.
8. В script.js замените PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE на этот URL.
9. Загрузите обновлённые файлы в GitHub.

Почему этот шаг нельзя сделать автоматически: URL веб-приложения появляется только после вашего подтверждения разрешений Google Apps Script.
